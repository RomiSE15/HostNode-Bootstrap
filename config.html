Performance & Optimization Guide

This documentation adapts automatically to different screen resolutions, scaling text size between desktop, tablet, and mobile displays for clear reading

Key Configuration Areas

Optimization

Lower view-distance to 6-8 chunks to reduce CPU load on shared home Wi-Fi networks

Crash Prevention

Set max-tick-time=-1 to disable the watchdog timer and prevent spontaneous timeouts

Accessibility

Disable online-mode=false to allow testing accounts without official authentication
